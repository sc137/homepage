# Publishing a note with Pandoc

Write Markdown in posts/_resources/ and publish an HTML file in posts/.
The source file is retained; HTML is committed for static GitHub Pages hosting.

For example, from the repository root:

    pandoc posts/_resources/encrypt-tax-docs.md \
      --standalone \
      --template posts/_resources/template.html \
      --output posts/encrypt-tax-docs.html

The shared Pandoc template automatically links ../styles.css from the published
/posts/ page. No browser-side Markdown renderer is required.

The heading in the Markdown file (e.g., "# Article Title") becomes the page
heading. The Pandoc title metadata, if supplied, sets the browser title.

For a new note, add the published URL to notes/index.html and sitemap.txt.
Avoid relocating old article URLs, which may already be linked externally.

Local preview from the repository root:

    python3 -m http.server 8000 --bind 127.0.0.1

Open http://localhost:8000/ to verify links, typography, and light/dark mode.
Do not run this layout against /msac, /emeritus, or music.html: those pages are
intentionally independent from the shared site style.
